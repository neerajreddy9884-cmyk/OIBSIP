## 📝 Project Description

## 🚀 How to Run the Program
1. Make sure you have Python 3 installed on your device.
2. Open your terminal, command prompt, or Python IDE (like Pydroid 3).
3. Run the script using the following command:
   ```bash
   python bmi_calculator.py
   ```
4. Enter your metrics using numeric digits when prompted by the terminal interface.
